
Facebook VIP Login System (PHP + SQLite + File Save)

How to run:
1. Install XAMPP or any local server.
2. Place this folder in the htdocs directory (e.g., C:/xampp/htdocs/facebook_vip_php).
3. Start Apache from XAMPP Control Panel.
4. Visit http://localhost/facebook_vip_php/index.html
5. Enter any username and password and click Log In.
6. Check users.txt and users.db for saved data.
